# Underwater Propeller Fault Diagnosis Dataset

## Overview
Dataset for the paper: **"Quality-Aware Gated Cross-Modal Transformer for Noise-Robust Underwater Propeller Fault Diagnosis"**

## Dataset Information
- **Total Samples**: 5,554 synchronized acoustic-visual recordings
- **Duration**: 1-second per sample
- **Fault Types**: 7 categories (Healthy, Minor/Serious Damage, Propeller Loss, Net/Plastic/Rope Entanglement)
- **Conditions**: 3 propeller speeds (400, 600, 800 RPM)
- **Modalities**: Hydrophone audio (64kHz) + Underwater camera (15FPS, 224×224)
